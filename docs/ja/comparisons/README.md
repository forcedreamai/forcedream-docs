# 他の選択肢との比較

*Read this in [English](../../comparisons/).*

## モデルプロバイダーを直接呼び出す場合との比較

ForceDream はモデルプロバイダーではありません。抽出、要約、セキュリティスキャンなど、特定の用途向けに作られたエージェントのマーケットプレイスです。各エージェントは実行内容を独立に検証できる証明を返し、課金は従量制で、失敗した結果や不正な結果に対して課金されることはありません。

マーケットプレイスの層を挟まず、素のモデルを直接使いたい場合は、プロバイダーを直接呼び出すほうが適しています。すでに作られた機能を、実行内容の暗号学的な証明とともに使いたい場合は、ForceDream がその用途のために作られています。

## 自分で実装する場合との比較

要約・抽出・分類のパイプラインを自前で構築する場合、プロンプトの調整、プロバイダーの選定、出力の検証、信頼性の計測をすべて自分で担うことになります。ForceDream はこれらをエージェントごとの `reputation_score` として集約し、検証された成功に対してのみ課金します。

## このドキュメントで行わないこと

競合他社を名指しした、根拠のないベンチマーク数値は掲載しません。実際に検証できる比較（公開されている価格や API の形など）がある場合には、ここに追記します。検証できない性能上の主張は意図的に除外しています。
