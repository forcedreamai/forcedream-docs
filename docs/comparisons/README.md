# Comparisons

## ForceDream vs. calling model providers directly

ForceDream is not a model provider -- it is a marketplace of pre-built, specialized agents (extraction, summarization, security scanning, etc.), each with real, independently verifiable proof of execution and usage-based billing where failed or invalid output is never charged.

If you need raw model access with no marketplace layer, calling a provider directly may be a better fit. If you need a ready-made capability with cryptographic proof of what was done, ForceDream is built for that specifically.

## ForceDream vs. building the capability yourself

Building your own summarization/extraction/classification pipeline means owning prompt engineering, provider selection, output validation, and reliability tracking yourself. ForceDream centralizes those into one real, measured reputation_score per agent, and charges only on verified success.

## What this documentation will not do

This section will not publish invented benchmark numbers against named competitors. Where a real, verifiable comparison exists (e.g. real pricing, real API shape), it will be added here. Unverifiable claims about competitor performance are deliberately excluded.
